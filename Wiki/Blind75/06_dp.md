## 1. LeetCode 70: Climbing Stairs (Easy)

* **Identified Pattern Upfront:** Recursion / Memoization / DP
* **Time Taken:** 14 minutes
* **Solution Folder:** [`../../DP/70.%20Climbing%20Stairs/`](../../DP/70.%20Climbing%20Stairs/)
* **Submittion Link:** [`Link`](https://leetcode.com/problems/climbing-stairs/submissions/2148375956)

### Code Solution

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        # Edge case
        if n == 1:
            return 1
        
        # DP table for (n+1)th position
        dp = [0] * (n+1)

        # Default values
        dp[1] = 1
        dp[2] = 2

        for i in range(3, n+1):
            # running sum for both 1 step & 2 steps
            dp[i] = dp[i-1] + dp[i-2]

        # Last element stores answer
        return dp[n]


obj = Solution()
print(obj.climbStairs(2))       # 2
print(obj.climbStairs(3))       # 3

# T.C: O(N)     --> Running loop on N numbers
# S.C: O(N)     --> DP array of N size used
```

## 2. LeetCode 322: Coin Change (Medium)

* **Identified Pattern Upfront:** Recursion / Memoization / DP
* **Time Taken:** 19 minutes
* **Solution Folder:** [`../../DP/322.%20Coin%20Change/`](../../DP/322.%20Coin%20Change/)
* **Submittion Link:** [`Link`](https://leetcode.com/problems/coin-change/submissions/2148407847)

### Code Solution

```python
from typing import List

class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        # (amount+1) ~ inf
        dp = [amount+1] * (amount+1)

        # 0 coins for 0 amount
        dp[0] = 0

        for a in range(1, amount+1):
            for c in coins:
                # If amount doesn't become -ve
                if a - c >= 0:
                    # Without coin c
                    con1 = dp[a]

                    # With coin + pre-calculated
                    con2 = 1 + dp[a - c]

                    # Minimum number of coins
                    dp[a] = min(con1, con2)

        # Return coins if combination made else -1
        return dp[amount] if dp[amount] != amount + 1 else -1


obj = Solution()
print(obj.coinChange([1, 2, 5], 11))            # 3
print(obj.coinChange([2], 3))                   # -1
print(obj.coinChange([1], 0))                   # 0

# T.C: O(N)     --> Running loop amount times + N coins
# S.C: O(amount)     --> DP array of "amount" size used
```

## 3. LeetCode 198: House Robber (Medium)

* **Identified Pattern Upfront:** Recursion / Memoization / DP
* **Time Taken:** 5 minutes
* **Solution Folder:** [`../../DP/198.%20House%20Robber/`](../../DP/198.%20House%20Robber/)
* **Submittion Link:** [`Link`](https://leetcode.com/problems/house-robber/submissions/2149373108)

### Code Solution

```python
# Tabulation
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)

        # Edge case
        if n == 1:
            return nums[0]

        # DP array
        dp = [0] * n

        # Set default robbed values
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])

        for i in range(2, n):
            # SKIP
            skip = dp[i-1]

            # ROB: Ignore adjacent house
            rob = nums[i] + dp[i-2]

            # Save maximum amount
            dp[i] = max(skip, rob)

        # Last index holds answer
        return dp[n-1]

    
obj = Solution()
print(obj.rob([1, 2, 3, 1]))            # 4
print(obj.rob([2, 7, 9, 3, 1]))         # 12

# T.C: O(N)     --> Running loop on N numbers
# S.C: O(N)     --> DP array of N size used
```

## 4. LeetCode 213: House Robber II (Medium)

* **Identified Pattern Upfront:** Recursion / Memoization / DP
* **Time Taken:** 40 minutes
* **Solution Folder:** [`../../DP/213.%20House%20Robber%20II/`](../../DP/213.%20House%20Robber%20II/)
* **Submittion Link:** [`Link`](https://leetcode.com/problems/house-robber-ii/submissions/2149422607)

### Code Solution

```python
# Tabulation
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        
        # Edge case: Single house
        if n == 1:
            return nums[0]

        def rob_helper(nums, start, end):
            length = end - start

            # If the slice is empty (happens with very small inputs)
            if length == 0: return 0
            # If the slice has one house, max is just that house
            if length == 1: return nums[start]

            # DP array
            dp = [0] * length

            # Set default robbed values
            dp[0] = nums[start]
            dp[1] = max(nums[start], nums[start+1])

            for i in range(2, length):
                # SKIP
                skip = dp[i-1]

                # ROB: Ignore adjacent house
                # Mapped i to nums index
                rob = nums[start+i] + dp[i-2]

                # Save maximum amount
                dp[i] = max(skip, rob)

            # Last index holds answer
            return dp[length-1]

        # SKIP last house
        con1 = rob_helper(nums, 0, n-1)

        # SKIP 1st house
        con2 = rob_helper(nums, 1, n)

        # MAX from circular condition
        return max(con1, con2)


obj = Solution()
print(obj.rob([2, 3, 2]))            # 3
print(obj.rob([1, 2, 3, 1]))         # 4
print(obj.rob([1, 2, 3]))            # 3
print(obj.rob([1, 2, 1, 1]))            # 3

# T.C: O(N)     --> Running loop on N numbers
# S.C: O(N)     --> DP array of N size used
```

## 5. LeetCode 62: Unique Paths (Medium)

* **Identified Pattern Upfront:** Recursion / Memoization / DP
* **Time Taken:** 7 minutes
* **Solution Folder:** [`../../DP/62.%20Unique%20Paths/`](../../DP/62.%20Unique%20Paths/)
* **Submittion Link:** [`Link`](https://leetcode.com/problems/unique-paths/submissions/2149439494)

### Code Solution

```python
# Tabulation (Space optimized)
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        # DP table, last position holds answer
        dp = [1] * (n)

        # Looping (1,n) m-1 times
        for _ in range(m - 1):
            for j in range(1, n):
                # Update unique paths: with sum of prev + curr
                dp[j] = dp[j] + dp[j-1]

        # Return answer
        return dp[n-1]


obj = Solution()
print(obj.uniquePaths(3, 7))             # 28
print(obj.uniquePaths(3, 2))             # 3
print(obj.uniquePaths(23, 12))           # 193536720

# T.C: O(M * N)     --> Looping on grid
# S.C: O(M * N)     --> 1-D DP array
```

## 6. LeetCode 300: Longest Increasing Subsequence (Medium)

* **Identified Pattern Upfront:** Recursion / Memoization / DP
* **Time Taken:** 16 minutes
* **Solution Folder:** [`../../DP/300.%20Longest%20Increasing%20Subsequence/`](../../DP/300.%20Longest%20Increasing%20Subsequence/)
* **Submittion Link:** [`Link`](https://leetcode.com/problems/longest-increasing-subsequence/submissions/2150544194)

### Code Solution

```python
from typing import List


class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)

        # DP array for storing LIS
        dp = [1] * n

        # Looping through all numbers
        for i in range(1, n):
            # Looping through previous numbers
            for j in range(i):
                # If previous number is smaller, then ith number can be in LIS.
                if nums[j] < nums[i]:
                    # Compare current number with Potential new length
                    dp[i] = max(dp[i], dp[j]+1)

        # MAX of DP is LIS
        return max(dp)


obj = Solution()


# Test Case 1
nums = [10, 9, 2, 5, 3, 7, 101, 18]
print(obj.lengthOfLIS(nums))    # 4


# Test Case 2
nums = [0, 1, 0, 3, 2, 3]
print(obj.lengthOfLIS(nums))    # 4


# Test Case 3
nums = [7, 7, 7, 7, 7, 7, 7]
print(obj.lengthOfLIS(nums))    # 1

# T.C: O(N^2)     --> Nested loop over the array to fill dp
# S.C: O(N)       --> dp array of size N
```

## 7. LeetCode 1143: Longest Common Subsequence (Medium)

* **Identified Pattern Upfront:** Recursion / Memoization / DP
* **Time Taken:** 17 minutes
* **Solution Folder:** [`../../DP/1143.%20Longest%20Common%20Subsequence/`](../../DP/1143.%20Longest%20Common%20Subsequence/)
* **Submittion Link:** [`Link`](https://leetcode.com/problems/longest-common-subsequence/submissions/2150586703)

### Code Solution

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m = len(text1)
        n = len(text2)

        # Track LCS
        lcs = 0

        # DP initialization with list comprehension
        # dp = [[0] * (n + 1) for _ in range(m + 1)]
        dp = []
        # 2D DP array
        for _ in range(m + 1):
            dp.append([0] * (n + 1))


        for i in range(m):
            for j in range(n):
                # If letter matched
                if text1[i] == text2[j]:
                    dp[i][j] = dp[i-1][j-1] + 1
                # If not matched, take max of top & left neighbor
                else:
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])

                # Update length with maximum one
                lcs = max(lcs, dp[i][j])

        # for i in range(len(dp)):
        #     lcs = max(lcs, max(dp[i]))

        return lcs


obj = Solution()


# Test Case 1
text1 = "abcde"
text2 = "ace"
print(obj.longestCommonSubsequence(text1, text2))    # 3


# Test Case 2
text1 = "abc"
text2 = "abc"
print(obj.longestCommonSubsequence(text1, text2))    # 3


# Test Case 3
text1 = "abc"
text2 = "def"
print(obj.longestCommonSubsequence(text1, text2))    # 0

# T.C: O(M * N)     --> M = len(text1), N = len(text2), filling the dp table
# S.C: O(M * N)     --> dp table of size (M+1) x (N+1)
```

## 8. LeetCode 139: Word Break (Medium)

* **Identified Pattern Upfront:** Recursion / Memoization / DP
* **Time Taken:** 36 minutes
* **Solution Folder:** [`../../DP/139.%20Word%20Break/`](../../DP/139.%20Word%20Break/)
* **Submittion Link:** [`Link`](https://leetcode.com/problems/word-break/submissions/2150620077)

### Code Solution

```python
from typing import List


class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        n = len(s)

        # Creating set for O(1) lookup
        words = set(wordDict)

        # DP array with False as initial state
        dp = [False] * (n+1)

        # Base case: empty string
        dp[0] = True

        # Looking for sub-strings for each s[i]
        for i in range(1, n + 1):
            for j in range(i):
                # If sub-string amtches the word
                if dp[j] and s[j:i] in words:
                    # Set True
                    dp[i] = True
                    # Breaking for sub-string
                    break

        # Store final answer
        return dp[n]


obj = Solution()


# Test Case 1
s = "leetcode"
wordDict = ["leet", "code"]
print(obj.wordBreak(s, wordDict))    # True


# Test Case 2
s = "applepenapple"
wordDict = ["apple", "pen"]
print(obj.wordBreak(s, wordDict))    # True


# Test Case 3
s = "catsandog"
wordDict = ["cats", "dog", "sand", "and", "cat"]
print(obj.wordBreak(s, wordDict))    # False

# T.C: O(N^2 * k)     --> N = len(s), nested loop plus substring slicing/lookup
# S.C: O(N + M)   --> dp array of size N, wordSet of total dict characters M
```

## 9. LeetCode 39: Combination Sum (Medium)

* **Identified Pattern Upfront:** Recursion / Backtracking
* **Time Taken:** 15 minutes
* **Solution Folder:** [`../../Backtrack/39.%20Combination%20Sum/`](../../Backtrack/39.%20Combination%20Sum/)
* **Submittion Link:** [`Link`](https://leetcode.com/problems/combination-sum/submissions/2152683490)

### Code Solution

```python
from typing import List

class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        n = len(candidates)

        result, comb = [], []
        total = 0

        def backtrack(i,total):
            # Base condition
            if total == target:
                result.append(comb.copy())
                return

            # Invalid sum condition
            if i == n or total > target:
                return

            # Add to comb
            comb.append(candidates[i])

            # Cond1: Picked & backtrack
            backtrack(i, total+candidates[i])

            # UNDO
            comb.pop()

            # Cond2: Not Picked
            backtrack(i+1,total)

        # Start backtracking
        backtrack(0,total)

        return result


obj = Solution()
print(obj.combinationSum([2, 3, 6, 7], 7))              # [[2,2,3],[7]]
print(obj.combinationSum([2, 3, 5], 8))                 # [[2,2,2,2],[2,3,3],[3,5]]
print(obj.combinationSum([2], 1))                       # []

# T.C: O(K * 2^T), O(N ^ (T/M))  --> where T is the target, M is the minimum value in candidates, and N is the length of candidates.
# S.C: O(N)                      -->  Recursive call stack used
```

## 10. LeetCode 91: Decode Ways (Medium)

* **Identified Pattern Upfront:** Recursion / Memoization / DP
* **Time Taken:** 30 minutes
* **Solution Folder:** [`../../DP/91.%20Decode%20Ways/`](../../DP/91.%20Decode%20Ways/)
* **Submittion Link:** [`Link`](https://leetcode.com/problems/decode-ways/submissions/2152739361)

### Code Solution

```python
class Solution:
    def numDecodings(self, s: str) -> int:
        # Edge case: leading zero
        if s[0] == "0":
            return 0
        
        # dp array of size s+1
        n = len(s)
        dp = [0] * (n + 1)

        # Set default values
        dp[0] = 1
        dp[1] = 1

        for i in range(2, n + 1):
            single = s[i-1]
            double = s[i-2:i]

            # Updation for single character
            if single != "0":
                dp[i] += dp[i-1]

            if 10 <= int(double) <= 26:
                dp[i] += dp[i-2]
        
        # Last index holds possible ways
        return dp[n]


obj = Solution()
print(obj.numDecodings("12"))   # 2
print(obj.numDecodings("226"))  # 3
print(obj.numDecodings("06"))   # 0

# T.C: O(N)     --> Looping through N length string
# S.C: O(N)     --> DP array of size N used
```

## 11. LeetCode 55: Jump Game (Medium)

* **Identified Pattern Upfront:** DP / Greedy
* **Time Taken:** 10 minutes
* **Solution Folder:** [`../../Greedy-Algo/55.%20Jump%20Game/`](../../Greedy-Algo/55.%20Jump%20Game/)
* **Submittion Link:** [`Link`](https://leetcode.com/problems/jump-game/submissions/2152749739)

### Code Solution

```python
class Solution:
    def canJump(self, nums: list[int]) -> bool:
        n = len(nums)

        # Edge case: 1 jump
        if n == 1:
            return True

        max_reach = 0

        for i, jump in enumerate(nums):
            # Index out of bound
            if i > max_reach:
                return False
            
            # Update max_reach with index after jump
            max_reach = max(max_reach, i + jump)

            # If we comes to last index
            if max_reach >= n - 1:
                return True
        
        # Can't reach
        return False


obj = Solution()
print(obj.canJump([2,3,1,1,4]))     # True
print(obj.canJump([3,2,1,0,4]))     # False

# T.C: O(N)     --> Looping through N numbers
# S.C: O(1)     --> No data structure used

```
