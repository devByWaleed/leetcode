## 1. LeetCode 70: Climbing Stairs (Easy)

* **Identified Pattern Upfront:** Recursion / Memoization / DP
* **Time Taken:** 14 minutes
* **Solution Folder:** [`../../DP/70.%20Climbing%20Stairs/`](../../DP/70.%20Climbing%20Stairs/)
* **Submittion Link:** [`Link`](https://leetcode.com/problems/climbing-stairs/submissions/2148375956)

### Code Solution

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        # Edge case
        if n == 1:
            return 1
        
        # DP table for (n+1)th position
        dp = [0] * (n+1)

        # Default values
        dp[1] = 1
        dp[2] = 2

        for i in range(3, n+1):
            # running sum for both 1 step & 2 steps
            dp[i] = dp[i-1] + dp[i-2]

        # Last element stores answer
        return dp[n]


obj = Solution()
print(obj.climbStairs(2))       # 2
print(obj.climbStairs(3))       # 3

# T.C: O(N)     --> Running loop on N numbers
# S.C: O(N)     --> DP array of N size used
```

## 1. LeetCode No.: Name (Difficulty)

* **Solution Folder:** [`../../DP/322.%20Coin%20Change/`](../../DP/322.%20Coin%20Change/)
* **Submittion Link:** [`Link`](https://leetcode.com/problems/coin-change/submissions/2148407847)

### Code Solution

```python
from typing import List

class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        # (amount+1) ~ inf
        dp = [amount+1] * (amount+1)

        # 0 coins for 0 amount
        dp[0] = 0

        for a in range(1, amount+1):
            for c in coins:
                # If amount doesn't become -ve
                if a - c >= 0:
                    # Without coin c
                    con1 = dp[a]

                    # With coin + pre-calculated
                    con2 = 1 + dp[a - c]

                    # Minimum number of coins
                    dp[a] = min(con1, con2)

        # Return coins if combination made else -1
        return dp[amount] if dp[amount] != amount + 1 else -1


obj = Solution()
print(obj.coinChange([1, 2, 5], 11))            # 3
print(obj.coinChange([2], 3))                   # -1
print(obj.coinChange([1], 0))                   # 0

# T.C: O(N)     --> Running loop amount times + N coins
# S.C: O(amount)     --> DP array of "amount" size used
```
